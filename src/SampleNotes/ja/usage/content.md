# 操作ヘルプ

![折りたたみと展開位置の概要](assets/window-position-guide.png)

この付箋は編集ロック中です。本文やタイトル文字列は保護されますが、チェックボックス、表示サイズ、位置、色などは調整できます。

## 基本操作

- 本文をダブルクリック: 編集モードに切り替え
- `Esc`: 閲覧モードに戻る
- タイトルバーをクリック: 折りたたみ / 展開
- タイトルバーをドラッグ: 付箋を移動
- リンクをクリック: リンクを開く
- 編集モード中のリンクは `Ctrl + クリック` で開く

## マウスホイール

| 場所 | 操作 |
| --- | --- |
| 本文 | `Ctrl + ホイール` で本文フォントサイズ変更 |
| タイトルバー | `Ctrl + ホイール` でタイトルフォントサイズ変更 |
| 画像 | `Ctrl + ホイール` で画像表示サイズ変更 |

## 移動とスナップ

- 通常ドラッグ: 折りたたみ時と展開時の位置を同期
- `Shift + ドラッグ`: 折りたたみ時と展開時の位置を別々に調整
- `Alt + ドラッグ`: スナップを無効化
- `Alt + Shift + ドラッグ`: スナップなしで、現在の状態だけ位置調整

## タイトル右クリックメニュー

- タイトルを編集
- 重なり順を変更
- 透明度を変更
- 折りたたみ中の「展開位置をここにする」
- 編集をロック
- 非表示
- 削除

編集ロック中は、タイトル文字列の編集と削除はできません。

## 本文右クリックメニュー

- 切り取り / コピー / 貼り付け
- Markdownリンクとして貼り付け
- Excel表の貼り付け / コピー
- リンクを開く
- Markdownリンクに変換
- ウィンドウを画像にフィット
- 編集をロック
- 非表示
- 削除

編集ロック中は、本文の入力、貼り付け、リンク変換、画像の追加や削除はできません。

## タイトルバーのボタン

| ボタン | 動作 |
| --- | --- |
| + | この付箋の色・アイコン・フォントを引き継いで新規作成 |
| 📌 | 常に最前面 |
| ▲ / ▼ | 折りたたみ / 展開 |
| 🔒 | 編集ロック中の表示 |

鍵は状態表示だけです。クリック対象ではないので、ドラッグや折りたたみ操作の邪魔になりません。

## タスクトレイ

- 左クリック: 全付箋の表示 / 非表示
- 右クリック: 非表示の付箋を再表示、新規作成、設定、終了
- 設定: 保存フォルダ、エクスポート、インポート、言語、ダークモードなど

## 保存とバックアップ

- 保存場所: `%APPDATA%\ScreenStickyNotes`
- 付箋は `notes` フォルダ内に、1枚ずつ `meta.json`、`content.md`、`assets` として保存されます
- 「付箋をエクスポート...」で zip バックアップを作成できます
- 「付箋をインポート...」は既存付箋を上書きせず、追加として取り込みます
