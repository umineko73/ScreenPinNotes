# 基本操作マニュアル

![折りたたみと展開位置の概要](assets/window-position-guide.png)

## 編集と表示

- 本文をダブルクリック: 編集モードに切り替え
- Esc: 閲覧モードに戻る
- 閲覧モードではリンク、チェックリスト、画像操作が使えます

## 付箋の移動

- タイトルバーをドラッグ: 付箋を移動
- タイトルバーをクリック: 折りたたみ / 展開
- 折りたたみ時と展開時の位置・サイズは別々に保存されます
- 折りたたみ状態で移動すると、次回展開位置は自動調整されます
- タイトル上で右クリック: タイトル編集、重なり順、透明度、展開位置、非表示、削除

## 折りたたみと展開

- 画面下に置いた付箋を展開しても、画面外へ隠れないように調整されます
- 折りたたみ中に「展開位置をここにする」を選ぶと、展開時の位置をリセットできます

## タイトルバーのボタン

| ボタン | 動作 |
| --- | --- |
| + | この付箋の色・アイコン・フォントを引き継いで追加 |
| ピン | 常に最前面 |
| ▲ / ▼ | 折りたたみ / 展開 |

## タスクトレイ

- 左クリック: 全付箋の表示 / 非表示
- 右クリック: 非表示の付箋を再表示、新規作成、言語切り替え、ダークモード、終了

## 保存場所

`%APPDATA%\ScreenStickyNotes`
