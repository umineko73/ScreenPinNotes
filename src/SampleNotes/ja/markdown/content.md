# Markdown 書式一覧

本文で使える Markdown 記法を一覧にまとめます。編集ロック中でも、チェックボックスの切り替え、本文/タイトル/画像の表示サイズ変更はできます。

## Markdown入力補助

編集中に文字列を選択して右クリックし、**Markdown書式** から太字、取り消し線、インラインコード、見出し1〜3、箇条書き、チェックリスト、リンクを選べます。行の書式は選択がかかる行全体に適用します。太字などは選択がないと記号の間にカーソルを置き、対応する同じ書式の再選択で解除できます。`Ctrl+Z` で元に戻せます。

既存リンク内にカーソルを置いて **リンクを編集...** を選ぶと、表示テキストとURLを別々に編集できます。URLは折り返し表示され、ダイアログは拡大できます。**Markdown書式 > リンクを挿入・編集...** から新規リンクも作成できます。

任意の書式の組み合わせを検証・修正する機能ではありません。描画失敗時は原文表示へ切り替えます。深い入れ子（16段）、長いインライン文字列（8,192文字超）、大きい文書（131,072文字超または改行2,000個超）は解析を制限して原文を表示します。本文自体は削除しません。

## インライン記法

| 種類 | 書き方 | 表示例 |
| --- | --- | --- |
| 太字 | `**重要**` または `__重要__` | **重要** |
| 斜体 | `*補足*` または `_補足_` | *補足* |
| 打ち消し線 | `~~削除~~` | ~~削除~~ |
| インラインコード | `` `Ctrl+C` `` | `Ctrl+C` |
| Markdownリンク | `[OpenAI](https://openai.com/)` | [OpenAI](https://openai.com/) |
| URL自動リンク | `https://www.google.com` | https://www.google.com |
| Windowsパス自動リンク | `C:\Users` | C:\Users |
| エスケープ | `\*そのまま表示\*` | \*そのまま表示\* |

## ブロック記法

| 種類 | 書き方 | 表示例 |
| --- | --- | --- |
| 見出し1から6 | `# 見出し1` から `###### 見出し6` | 下の「見出し」 |
| 箇条書き | `- 項目`、`* 項目`、`+ 項目` | 下の「箇条書き」 |
| 番号付きリスト | `1. 項目` | 下の「番号付きリスト」 |
| チェックリスト | `- [ ] 未完了`、`- [x] 完了` | 下の「チェックリスト」 |
| 引用 | `> 引用文` | 下の「引用」 |
| 水平線 | `---`、`***`、`___` | 下の「水平線」 |
| コードブロック | バッククォート3つの行で囲む | 下の「コードブロック」 |
| 表 | `\| 列1 \| 列2 \|` と区切り行 `\| --- \| --- \|` | 下の「表」 |
| 表の左揃え | `\| :--- \|` | 下の「表」 |
| 表の中央揃え | `\| :---: \|` | 下の「表」 |
| 表の右揃え | `\| ---: \|` | 下の「表」 |

## ブロック記法の表示例

### 見出し

# 見出し1
## 見出し2
### 見出し3

### 箇条書き

- 項目A
* 項目B
+ 項目C

### 番号付きリスト

1. 1つ目
2. 2つ目

### チェックリスト

- [x] 完了した項目
- [ ] 閲覧モードや編集ロック中でもクリックして切り替え

### 引用

> 引用文の表示例です。

### 水平線

---

### 表

| 左揃え | 中央揃え | 右揃え |
| :--- | :---: | ---: |
| A | B | C |

### コードブロック

```csharp
var note = "Markdown対応";
Console.WriteLine(note);
```

## 画像

| 種類 | 書き方 |
| --- | --- |
| 画像 | `![説明](assets/image.png)` |
| 幅指定 | `![説明](assets/image.png){width=320}` |

インライン表示はローカル画像のみです。この付箋の `assets` フォルダ内のファイルやWindowsパスを指定できます。画像URLは記法として扱えますが、画像プレビューは表示しません。貼り付けた画像はこの付箋の `assets` フォルダへ保存されます。

## 操作で作れる書式

| 操作 | 作られる/変更されるもの |
| --- | --- |
| 画像貼り付け | `![説明](assets/...)` |
| 画像上で `Ctrl + マウスホイール` | 画像の `{width=...}` を変更 |
| 本文上で `Ctrl + マウスホイール` | 本文フォントサイズを変更 |
| タイトルバー上で `Ctrl + マウスホイール` | タイトルフォントサイズを変更 |
| Excel範囲の貼り付け | Markdown表 |
| Markdownリンクとして貼り付け | `[表示名](URL)` |
