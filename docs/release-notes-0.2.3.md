# v0.2.3

不具合修正版です。

- 1行表示の幅を調整したあと、展開時のサイズが1行表示のサイズで上書きされる問題を修正しました。
- 非アクティブな付箋のタイトルをクリックした際、前面化と同時に折りたたみ／展開が実行される問題を修正しました。タイトルをドラッグして移動する操作は引き続き利用できます。

Bug-fix release.

- Preserve expanded note dimensions when unfolding after resizing the single-line view.
- Bring inactive notes forward on the first title click without also toggling the folded view. Title dragging remains available.

## Downloads

- `ScreenPinNotes-0.2.3-win-x64.zip`: .NETランタイム同梱 / self-contained.
- `ScreenPinNotes-0.2.3-win-x64-runtime.zip`: .NET 8 Desktop Runtimeが必要 / requires the .NET 8 Desktop Runtime.
