# v0.2.7

## 日本語

- 毎週のリマインダーで「1週目〜5週目」を選べるようにしました（隔週など）。
- 毎月のリマインダーで「最終日」を選べるようにしました。
- 付箋のインポートで、同じフォルダーが既にある場合に上書き・別名・スキップを選べるようにしました。
- アプリとトレイのアイコンを新しくしました。
- リマインダーで点滅する付箋だけを前面に出すようにしました（設定でオフにできます）。
- 付箋を追加したときなどに、すべての付箋が他のアプリより前に出てしまう問題を修正しました。

## English

- Weekly reminders can be limited to the 1st–5th weeks of the month (e.g. every other week).
- Monthly reminders can use the last day of the month.
- Importing notes whose folders already exist lets you overwrite, rename or skip them.
- New app and tray icons.
- Only the flashing reminder note comes to the front (can be turned off in Settings).
- Fixed all notes jumping in front of other apps when, for example, a note was added.
