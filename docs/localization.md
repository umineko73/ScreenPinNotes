# 言語リソースの追加

翻訳は.NET標準のResourceManagerとresxで管理します。

- `src/Resources/Strings.resx`: 英語。未翻訳項目のフォールバック。
- `src/Resources/Strings.ja.resx`: 日本語。
- `LocalizationService.T(key)`: 現在の設定言語で取得。
- `LocalizationService.T(key, language)`: 指定言語で取得。

新しい言語は、英語ファイルを `Strings.fr.resx` などの名前で複製してvalueを翻訳します。`ja-JP`、`pt-BR`などの.NETカルチャー名も使えます。キーと`{0}`、`{0:0}`などの書式指定子は維持してください。未翻訳のキーは省略でき、英語へフォールバックします。

ビルドすると言語一覧を自動生成してアセンブリに埋め込みます。設定メニューには各言語の母語名が表示され、言語追加のためのC#編集は不要です。通常配布では生成された言語フォルダとresources.dllも同梱してください。単一ファイル配布では.NETのリソースバンドル機構を使用します。

地域別の言語は親言語へフォールバックします。新規設定ではOS言語から対応言語を選び、対応しない場合は英語です。既存設定の無効・未対応な言語は従来互換で日本語へ正規化します。

初期ヘルプは `src/SampleNotes/<言語コード>/` にusageとmarkdownのフォルダを追加します。選択言語のサンプルがない場合は英語を使用します。

追加後はビルドし、言語メニュー、文字の欠け、ダイアログ幅、書式指定子、サンプル付箋を確認してください。固定の製品名や記号まで翻訳する必要はありません。
