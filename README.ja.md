# ScreenPinNotes

[English](README.md) | 日本語

Windows 用のデスクトップ付箋アプリです。デスクトップに貼りっぱなしにでき、Markdown で表示され、アプリが無くても読めるテキストファイルとして保存されます。

![ScreenPinNotes のスクリーンショット](docs/screenshot.png)

## 特徴

- **邪魔にならない付箋** — タイトルバーだけに折りたたむ、あるいはタイトルバー自体を隠して本文1行目だけを残せます。画面端や他の付箋にスナップします。
- **付箋ごとの見た目** — 色・アイコン・本文フォント・タイトルフォント・不透明度・常に最前面を、付箋ごとに設定できます。ライト/ダークモード対応。
- **Markdown** — 見出し、リスト、クリックできるチェックリスト、表、コード、リンク、画像。編集中は右クリックから書式を挿入できます。
- **リマインダー** — 1回のみ・毎日・毎週・毎月。Windowsの通知に加えて、スヌーズ付きの通知ウィンドウも選べます。
- **どこからでも貼り付け** — 画像、Excelの表、Excel内の画像。
- **外部ファイル付箋** — `.md` / `.txt` を読み取り専用の付箋として表示し、ファイルの変更に追従します。
- **付箋一覧** — 全付箋を検索し、表示・非表示・削除をまとめて操作できます。
- **ただのローカルファイル** — 付箋1枚が1フォルダ、自動保存。日本語/英語UI。タスクトレイに常駐し、Windows起動時に自動起動もできます。

## ダウンロード

[Releases](https://github.com/umineko73/ScreenPinNotes/releases) からzipを取得して展開してください。インストールは不要です。

| ファイル | 必要なもの |
|----------|-----------|
| `ScreenPinNotes-x.y.z-win-x64.zip`（約68MB） | なし |
| `ScreenPinNotes-x.y.z-win-x64-runtime.zip`（約11MB） | [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) |

Windows 10 以降、x64。角丸表示は Windows 11 のみです。

## 使い方

| 操作 | 動作 |
|------|------|
| 本文をダブルクリック | 編集する |
| `Esc` / `Ctrl+Enter` / ツールバーの `✓` | 編集を終える（内容は破棄されません） |
| タイトルバーをドラッグ | 移動 |
| タイトルバーをダブルクリック | 折りたたむ / 展開する |
| タイトルまたは本文を右クリック | 付箋のメニュー |
| 本文・画像の上で `Ctrl`+ホイール | フォント / その画像のサイズ変更 |
| スクロールできる本文を右ボタンドラッグ | 本文をスクロール |
| 付箋のウィンドウを閉じる（タスクバーの `×`、`Alt+F4`） | その付箋を非表示にする（削除はされません） |
| トレイアイコンを左クリック / 右クリック | 全付箋の表示・非表示 / メニュー |

右クリックメニューの上と、編集中の付箋の下にミニツールバーが出ます。`A-` `A+` は本文サイズ、`T-` `T+` はタイトルサイズ、`Aa` はフォント、🦊 はアイコン、🎨 は色、緑の `✓` は編集の終了です。編集中の付箋は左下に「編集中」と表示されます。編集中にリサイズしたサイズは別に記憶されるので、通常表示の大きさは変わりません。

### 折りたたみ表示と展開表示

付箋ごとに、折りたたみ時と展開時の位置・幅を別々に記憶します。位置が離れている付箋はタイトルバーに `⛓️‍💥` が付き、**折りたたみ時の位置にそろえる** で揃えられます。

| タイトルバー上で | 動作 |
|------------------|------|
| `Ctrl` + ドラッグ | 今の表示の位置だけ動かす |
| `Alt` + ドラッグ | スナップせずに動かす |
| `Ctrl+Alt` + ドラッグ | 両方 |

### Markdown入力補助

編集中に文字列を選択して右クリックし、**Markdown書式** から太字、取り消し線、インラインコード、見出し、箇条書き、チェックリスト、リンクを挿入できます。同じ書式をもう一度選ぶと解除でき、`Ctrl+Z` で元に戻せます。**リンクを編集...** では既存リンクの表示テキストとURLを別々に編集できます。極端に大きい文書や深い入れ子は整形せず原文のまま表示します（内容は失われません）。

### 画像

貼り付けた画像は付箋フォルダの `assets` にPNGとして保存されます。サイズは右クリックまたは `Ctrl`+ホイールで20〜200%に変更でき、**画像に合わせて付箋のサイズを調整** で付箋の方を合わせられます。インライン表示されるのはローカル画像だけで、`http(s)://` の画像URLはMarkdownにはなりますがプレビューされません。

### リマインダー

付箋のメニューまたは付箋一覧から設定します。1回のみ・毎日・毎週（曜日を複数選択）・毎月（1〜31日、その日が無い月は月末）から選べます。リマインダー付きの付箋には `⏰` が付き、マウスを乗せると次回の時刻が分かります。

時刻になるとWindowsの通知が出ます。クリックすると付箋一覧が開き、同時刻の通知は1つにまとまります。完了・5分・15分・1時間スヌーズを選べる通知ウィンドウも併用でき、スヌーズしても繰り返しの時刻はずれません。通知にはトレイでの常駐が必要で、終了中に過ぎた予定は次の起動時に1回だけ通知されます。

### タスクトレイのメニュー

**付箋一覧...** では、タイトル・本文・リマインダー・外部ファイルのパスを横断検索でき、表示/非表示・リマインダー・削除をまとめて操作できます。非表示にした付箋は **非表示の付箋** から戻します（*付箋をすべて表示* では意図的に戻しません）。

**外部ファイルを付箋として開く...** では、`.md` / `.txt` を読み取り専用の付箋（`🔗` 付き）として表示し、ファイルの変更に追従します。ここで変えた画像サイズは付箋側の設定として保存され、元のファイルは変更しません。

**設定** には、新しい付箋の既定値、ダークモード、言語、スタートアップ登録、タスクバー表示、トレイアイコンの左クリック動作、折りたたみの挙動、保存フォルダ、エクスポート/インポートがまとまっています。変更はその場で反映・保存されます。新しい付箋の既定値はトレイから作った付箋に使われ、既存の付箋の `＋` から増やしたときはその付箋の見た目を引き継ぎます。

## Markdown 記法

編集モードでは Markdown ソース、閲覧モードでは整形結果を表示します。

| 記法 | 効果 |
|------|------|
| `# 見出し` 〜 `###### 見出し` | 見出し（6段階） |
| `**太字**` / `__太字__` | 太字 |
| `*斜体*` / `_斜体_` | 斜体 |
| `~~取り消し~~` | 取り消し線 |
| `` `コード` `` / ` ```ブロック``` ` | インラインコード / コードブロック |
| `- 項目` / `1. 項目` / `- [ ]` | リスト（チェックリストはクリックで切替） |
| `> 引用` / `---` | 引用 / 水平線 |
| `\| a \| b \|` | 表（`:---`、`:---:`、`---:` で列揃え） |
| `[表示名](url)` / `<https://example.com>` | リンク（URL内の `(` に対応。リンクタイトルは無視） |
| `![説明](assets/image.png)` | 画像（`{width=240}` でサイズ指定） |

`\*`、`\[` などの基本エスケープに対応しています。

## データの保存場所

```
%AppData%\ScreenPinNotes\
  settings.json
  logs\app.log
  notes\{付箋ID}\meta.json, content.md, assets\
```

付箋1枚が1フォルダです。`meta.json` に位置・サイズ・色・リマインダーなどの情報、`content.md` に本文、`assets` に画像が入ります。本文の上限は既定で1MBです（`MaxNoteContentBytes`）。

保存先はタスクトレイの **設定 > 保存フォルダを選択...**、または初回起動前の環境変数 `SCREENPINNOTES_DATA` で変更できます。付箋が無いフォルダにはサンプル付箋がコピーされます。`settings.json` を直接編集する場合はアプリを終了してから行ってください。

## ビルド

```bash
git clone https://github.com/umineko73/ScreenPinNotes.git
cd ScreenPinNotes
dotnet build
dotnet run --project src
```

ビルドには .NET 8 SDK が必要です。配布用zipは `powershell -ExecutionPolicy Bypass -File scripts/publish.ps1` で `artifacts/` に生成されます。

付箋1枚は1つのWPF `Window` で、`WindowStyle="None"` と独自タイトルバーで描画しています。ソースは `src/` 配下の `Models/`、`ViewModels/`、`Views/`、`Services/`、`SampleNotes/` に分かれています。
